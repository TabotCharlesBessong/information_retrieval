# Phase A Starter Source Allowlist

This list seeds the initial crawl scope for the African technology and startup news vertical.

## Inclusion Criteria

1. Primary focus on African technology, startups, venture, or ecosystem news.
2. Publicly accessible article pages.
3. Crawl-friendly structure with stable article URLs.

## Seed Sources (Initial)

1. TechCabal
- Base URL: https://techcabal.com
- Focus: African tech and startup news.

2. Disrupt Africa
- Base URL: https://disruptafrica.com
- Focus: Startup ecosystem and venture activity.

3. Benjamindada.com
- Base URL: https://www.benjamindada.com
- Focus: Startup news, ecosystem updates, and product launches.

4. WeeTracker
- Base URL: https://weetracker.com
- Focus: Venture, founders, and startup funding trends.

5. IT News Africa
- Base URL: https://www.itnewsafrica.com
- Focus: Enterprise and broader African technology news.

## Notes

1. Confirm robots.txt permissions before crawl jobs are enabled.
2. Enforce article-path patterns in crawler rules to reduce noise.
3. Revisit and refine the allowlist at each phase review checkpoint.
